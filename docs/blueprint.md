# **App Name**: TeamUp

## Core Features:

- Display Team Name: Display the team's name prominently on the home page or in the header.
- Add New Team Members: Provide a form with input fields for member details (name, role, contact info, and image upload). Upon submission, validate the input fields and store the data (including the uploaded image) in MongoDB via a backend API.
- View All Team Members: Fetch and display a list of all team members from the backend, using cards or a table layout. Each member should display their name, role, and profile image with a 'View Details' button/link.
- View Individual Member Details: On clicking a member, navigate to a detail page and display the full details of the selected member (full name, role, email/contact, profile image, and any additional details), fetched from the backend.

## Style Guidelines:

- Primary color: Light blue (#E0F7FA) for a calm and professional feel.
- Secondary color: Light gray (#F5F5F5) for backgrounds and subtle separation.
- Accent: Teal (#008080) for interactive elements like buttons and links.
- Clear and readable sans-serif fonts for all text.
- Use a clean and structured layout with consistent spacing and padding.
- Simple and professional icons for navigation and actions.
