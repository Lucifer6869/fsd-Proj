# Firebase Studio

This is a NextJS starter in Firebase Studio.

To get started, take a look at src/app/page.tsx.

## Connection to MongoDB

To connect the application to a MongoDB database, you need to set up the following environment variables:

*   **MONGODB_URI**: This variable should contain the connection string to your MongoDB instance.
    
    Example: `mongodb+srv://<username>:<password>@<cluster-address>/<options>`
*   **MONGODB_DB**: This variable should contain the name of the database you want to connect to within your MongoDB instance.

    Example: `myDatabase`
